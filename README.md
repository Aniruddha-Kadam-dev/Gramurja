# GramUrja Website Redesign

Welcome to the **GramUrja** repository! This repository contains the redesigned website for **GramUrja**, an NGO committed to promoting sustainable development in rural India through various community-driven initiatives.

This project is a complete revamp of the website, designed with modern web technologies to provide an improved user experience, performance, and accessibility.

## Table of Contents
- [About GramUrja](#about-gramurja)
- [Technologies Used](#technologies-used)
- [Features](#features)
- [Contributing](#contributing)

## About GramUrja
GramUrja is an NGO that works towards empowering rural communities by implementing sustainable energy solutions, educational programs, and improving healthcare infrastructure. The organization focuses on improving the quality of life in rural areas and promoting sustainable practices for long-term development.

For more information about the NGO, visit the <a href="https://gramurja.org/" target="_blank">GramUrja Website</a>.

## Technologies Used
This project was developed using a variety of web technologies to ensure responsiveness, performance, and accessibility.

- **HTML**: For the structure and content of the web pages.
- **CSS**: For styling and layout of the website.
- **JavaScript**: For dynamic interactions and enhancements.
- **Responsive Design**: Media queries and flexible layouts for optimal display across devices (desktop, tablet, mobile).
- **Font Awesome** (optional, if used): For scalable vector icons.

## Features
- **Modern Design**: A fresh, user-friendly, and modern design reflecting GramUrja's mission and initiatives.
- **Responsive Layout**: The website is fully responsive, ensuring it looks great on devices of all sizes.
- **Accessible**: The website follows best practices for web accessibility to cater to users with disabilities.
- **Interactive Elements**: Dynamic JavaScript features, such as modal windows, sliders, and smooth scrolling.
- **Content Sections**: Includes various sections like About Us, Our Mission, Projects, Events, and Contact Us.
